# MLP

Selected version: recorded buyer F1 65.22%. These are previously reported results on a reused test set, not independent confirmation.

Includes the executed notebook, saved trained pipeline and threshold, results and required model_helpers.py. Keep the helper beside the notebook. The serialized model is a dictionary; use its stored threshold to reproduce the reported result.

## Run
1. Extract the ZIP.
2. Open this folder in VS Code or Jupyter.
3. Install dependencies with `python -m pip install -r requirements.txt`.
4. Open `MLP.ipynb` and select Run All. Keep the folder structure intact.

Training can take several minutes and exact results can vary across dependency versions/platforms. The notebook already contains its recorded outputs.
